# Guide

Kumiki compiles a set of independent declarations into a plain browser app. This guide covers how to use it; the [specification](../spec/) defines what is correct.

Start at [Getting Started](./getting-started.md): install, write one file, run it. After that, go where your question is.

| Your question | Page |
|---|---|
| How do I write this file myself? | [Your First App](./your-first-app.md) |
| I know React. What changed? | [Thinking in Kumiki](./thinking-in-kumiki.md) |
| How do I do one specific thing? | [Recipes](./recipes.md) |
| Why is the language shaped like this? | [Design Philosophy](./design-philosophy.md) |
| Are the claims measured? | [Benchmarks](./benchmarks.md) |
| Can I just try it? | [Playground](./playground.md) |

Every feature also has a runnable file in [examples](https://github.com/kumikijs/Kumiki/tree/main/packages/examples).
